## 🌟 Возможности

### 📅 Умное расписание
- **Просмотр для групп и преподавателей** — гибкий поиск по университетской базе.
- **Два формата отображения** — удобное текстовое сообщение по дням или сгенерированное изображение на всю неделю.
- **Автоматическая рассылка** — модуль для отправки расписания в заданное время.

### ⚡ Высокая производительность
- **Интеллектуальный кэш** — данные институтов и кафедр обновляются раз в неделю для снижения нагрузки на API и мгновенного ответа.
- **Масштабируемая архитектура** — готово к высоким нагрузкам.

### 🔮 Планы на будущее
Интеграция с другими сервисами университета для создания единой цифровой экосистемы.

## 🌟 Features

### 📅 Smart Scheduling
- **View for Groups and Teachers** — Flexible search through the university database.
- **Two Display Formats** — Convenient daily text messages or a generated weekly image.
- **Automatic Notifications** — Module for sending schedules at a specified time.

### ⚡ High Performance
- **Intelligent Caching** — Institute and department data is updated weekly to reduce API load and ensure instant responses.
- **Scalable Architecture** — Ready for high load.

### 🔮 Future Plans
Integration with other university services to create a unified digital ecosystem.
